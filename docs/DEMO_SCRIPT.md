# OrderDesk demo (about 3 minutes)

Opening: “A supermarket’s inventory can say an item is available while a picker discovers it is damaged. That one discrepancy can break several customer orders. OrderDesk brings every affected order into one recovery plan.”

1. Show Overview and the sample orders across two branches.
2. Report four damaged Forma kettles, then build the recovery plan.
3. Point out four affected orders. Only two original kettles exist at Riverside, so those are reserved for the earliest delivery promises. The other two orders receive compatible replacement proposals.
4. Open OD-1041 and demonstrate branch confirmation, manager approval, packing, and release for dispatch.
5. Open OD-1043 and decline the replacement. Show the reservation released and a partial-order proposal requiring fresh customer consent.
6. Complete the remaining recoveries and show the incident close with zero order value at risk.
7. Open Activity trail, export the decisions, and explain the distinction between proposed savings and actual measured outcomes.

For the hosted demo, explicitly say: “This view uses sample data and simulated roles. The repository includes the Switch agent and persistent service; the live chat connection is a separate setup step.”

For a connected live recording, show the actual Switch/Mattermost chat and verified staff commands, then refresh the read-only live dashboard. Use the AI `explain` command only if a real provider is configured and tested.
